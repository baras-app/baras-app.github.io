## Setting a Log Directory

Upon first launching BARAS, you must set the combat log directory.

1. Ensure combat logging is enabled in SWTOR:
   - In-game: Preferences > Combat Logging > Enable Combat Logging
2. The default location is:
   - **Windows:** `C:\users\<YOUR_NAME_HERE>\Documents\Star Wars - The Old Republic\CombatLogs`
   - **Linux (Steam):** `~/.steam/steam/steamapps/compatdata/1286830/pfx/drive_c/users/steamuser/Documents/Star Wars - The Old Republic/CombatLogs`
   - **macOS:** `~/Documents/Star Wars - The Old Republic/CombatLogs`

![](/images/first-launch/01-log-directory-setup)

You can set the log directory in the **applications settings** window. This can be accessed by:

1. Clicking the blue hyperlinked `set log directory` text
2. OR cliking the &#9881; icon in the top-right to open the **application settings** menu

From this menu, you can set the location of the SWTOR combat logs

![](/images/first-launch/02-log-directory-modal)

Once your log directory is set, the application will automatically parse the latest log file in the directory. You will see a green visual
indicator that the app is "live" in the top-right corner of the header bar.

The application will always detect the newest log file in the directory and parse it without need for user interaaction.

## Application Navigation

![](/images/first-launch/03-header-navigation)

1. Overlay controls. Toggle visibility, lock/unlock the overlays, rearrange raid frames, and clear raid frames.
2. Overlay profile. Shows active profile. Click this element to switch between profiles.
3. Overlay customization menu. Opens a menu that manages overlay profiles and cutomizationo options.
4. Navigation pills. Navigates between the major pages of the app.
5. Log file menu. Open a window for selecting prior log files.
6. Application settings. Opens a menu for global application settings.
7. Current session info. Shows information about the active characte.
8. Parsely upload button
9. Operation timer control.
10. Alacrity/latency input.
11. Raid notes selection.
12. Overlay auto-hide controls.
13. Changelog and links to resources.

## Enabling Overlays

![](/images/first-launch/05-enabling-overlays)

1. Navigate to the **Overlays** control page via the navigation pill in the application header.
2. Click on the toggle button for a specific overlay to enable it. By default, overlays will appear in the top-left corner of
   the active monitor.
3. Global overlay visibility can be toggled either via the 👁 button in the header bar or the **Hidden/Visible** button on the overlay control page.
4. A prompt will appear in the application header prompting to save your changes to the current overlay profile. Changes must
   be saved in order to persist on application restart.

## Adjusting Overlays

![](/images/first-launch/06-overlay-movement)

To ajust overlay settings:

1. Toggle **Movement Mode** by clicking the lock button.
2. In movement-mode, you can click and drag a window to the desired screen posistion. Overlays will automatically snap to the
   nearest 10 pixel-increment. Resize overlays by dragging the bottom right corner.
