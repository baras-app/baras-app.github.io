## Overlay Profiles

Profiles let you save and switch between different overlay configurations. This is useful when you play multiple roles or specs — for example, a DPS layout with damage meters front and center vs. a healer layout with raid frames and HOT trackers prioritized.

A profile stores:
- Overlay positions and sizes
- Overlay appearance settings (colors, fonts, opacity)
- Which overlays are enabled
- Per-overlay configuration options

Up to **12 profiles** can be saved.

![Profile selector on the Overlays tab](/screenshots/profiles-selector.png)

---

## Creating a Profile

1. Set up your overlays the way you want them (enable, position, customize)
2. Navigate to the **Overlays** tab
3. Click **Save as Profile**
4. The profile is created with a default name and becomes the active profile

![Save as Profile button](/screenshots/profiles-save-as.png)

---

## Switching Profiles

There are two places to switch profiles:

### Overlays Tab

Select a profile from the **Profiles** dropdown on the Overlays tab. All overlays will update immediately to match the selected profile's settings.

### Header Bar

A compact **profile dropdown** in the header bar allows quick switching during gameplay without navigating to the Overlays tab.

![Quick profile switcher in header](/screenshots/profiles-selector.png)

---

## Saving Changes to a Profile

After making changes to your overlay layout or settings:

1. Make sure the profile you want to update is selected in the dropdown
2. Click the **save** icon (floppy disk) next to the dropdown
3. Your current settings overwrite the active profile

:::note
Changes to overlay positions, enabled state, and appearance are **not** automatically saved to the active profile. You must explicitly click save to update a profile.
:::

---

## Profile Behavior

- **Overlay visibility** (shown/hidden) is independent of profiles and persists across profile switches
- Switching profiles immediately updates all running overlays
- The last active profile is remembered across app restarts
- If no profiles exist, BARAS uses default settings

---

## Tips

- Create role-specific profiles: "Tank", "Healer", "DPS" with different overlay layouts
- Use the header dropdown for fast switching between pulls when you swap roles
- Create a minimal "Farming" profile with just personal stats for solo content
- Save a "Clean" profile with default positions as a reset point
